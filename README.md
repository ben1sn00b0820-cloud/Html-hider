# 墨序 Moxu｜HTML 原始碼隱藏器

SillyTavern 輕量擴充，版本 **1.0.2**。將聊天及思考區裡以 `<!DOCTYPE html` 或 `<html` 起頭的原始碼區塊隱藏，保留開關與命中數量。這份 GitHub 包與離線 1.0.2 使用相同執行程式，僅調整目錄與安裝說明。

## 從 GitHub 安裝

1. 複製倉庫網址：`https://github.com/ben1sn00b0820-cloud/Html-hider`。
2. 在酒館開啟「擴充功能 → 安裝擴充」，貼上倉庫網址並安裝。
3. 重新整理頁面，在「墨序 1.0.2｜HTML 原始碼隱藏」開啟「隱藏完整 HTML 原始碼」。
4. 查看「目前隱藏 X 個 HTML 原始碼區塊」。按「重新掃描」可重查已載入的訊息。

安裝後，可使用酒館擴充管理裡的更新功能取得倉庫的新版本。不要把 GitHub 網頁網址當成主題 JSON 匯入。

如果以前用過 `Moxu_v1.0.2_Install.cjs`，先用同一安裝器移除舊副本（會保留備份），再安裝 GitHub 版，避免重複資料夾或重複載入：

```bash
node "$HOME/storage/downloads/Moxu_v1.0.2_Install.cjs" --uninstall
```

安裝器不在這份 GitHub 包內；上述步驟僅適用於曾使用離線安裝器的使用者。若沒有用過，直接安裝即可。

## 主題

[Moxu_v1.0.2.json](Moxu_v1.0.2.json) 是選用的極簡深色主題，可下載後透過酒館的主題匯入功能安裝。擴充不會自動更換主題；原始碼隱藏不要求使用墨序主題。

## 功能與效能

- 支援未標記語言、巢狀容器、思考區、未閉合的 HTML 文件。
- 僅增加隱藏樣式，不刪聊天、不執行原始碼、不修改 API 設定。
- 保留一般程式碼、行內 HTML 範例及含真實 iframe 的區塊。
- 只觀察聊天 DOM，異動以 100ms 合併處理；辨識最多讀取前 2048 字元，沒有固定輪詢或外部資源請求。
- 關閉功能會恢復顯示並停用聊天觀察器。

這是顯示管理擴充，不是 HTML 前端渲染器。如果命中數為 0，內容可能在獨立 iframe 或非標準容器，仍需該前端的 DOM 資訊才能定位。尚未驗證特定手機或所有第三方渲染器。

原始 1.0.2 已通過 41 項代表性 Chromium DOM 檢查；GitHub 打包保留相同的 `index.js` 與 `style.css`。辨識限制和測試說明見 [詳細說明](DETAILS.md)。
